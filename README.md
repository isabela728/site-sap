# Site SAP - Interfaces Web

Projeto de desenvolvimento front-end com a recriação e prototipação de interfaces inspiradas no ecossistema **SAP**, contemplando desde o ambiente técnico/administrativo de customização até um portal moderno de autoatendimento com assistente virtual.

---

## Sobre o Projeto

Este projeto tem como objetivo exercitar habilidades de estruturação HTML5 e estilização CSS3 pura, reproduzindo com fidelidade visual telas do ambiente SAP:

1. **Tela 1 - Customização SAP (Web Dynpro / Floorplan Manager):**
   - Recriação da interface de configuração do componente `/SCMTMS/WDCC_FWD_ORDER` (*Forwarding Order*).
   - Elementos de barra de ferramentas (*Save, Edit, Undo, Redo, Drafts, Check*).
   - Painéis de navegação (*Repositories, Page Types, Page IDs*).
   - Tabelas de componentes e seções UIBB (*UI Building Blocks*).

2. **Tela 2 - Portal de Compras & Assistente Virtual:**
   - Interface amigável de autoatendimento com assistente virtual.
   - Menu rápido para requisição de materiais, serviços, consulta de fluxos e status de requisições.
   - Painel dinâmico de recomendações baseado no histórico de últimas compras.
